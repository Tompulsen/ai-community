# 浏览器本地数据与备份

聊天历史、图片作品、视频草稿和视频结果按 New API 数字用户 ID 分别保存到浏览器。同一个浏览器切换账号后会刷新并载入对应空间，不会自动把旧版未分账号的历史归给任一账号。旧数据需在账号页明确确认属于自己后认领，原始旧数据保留。

本次功能不增加聊天站的服务器数据库、对象存储或后台同步服务。New API 仍负责认证、密钥与计费。向模型发送内容、获取远程生成图片等操作仍需要网络请求。

## 跨设备迁移

1. 打开设置页的“本地数据与备份”。
2. 选择聊天记录、图片作品原图、显示与模型设置、视频记录链接，导出 JSON。
3. 在另一台设备登录，选择备份文件，核对待导入数量后确认导入。

默认合并并保留已有记录，ID 相同的会话、图片、视频跳过；选择“作为新副本导入”则生成新 ID。导入完成自动刷新。导入会暂停当前账号其他标签页的写入，并通知它们刷新，防止旧快照覆盖新数据。

备份不包含 API 密钥、账号登录凭据和进行中的任务凭据。文件含私人聊天及图片，请妥善保管。图片原图默认不勾选；备份上限为 512 MB，较大作品库可分别导出聊天和作品。视频备份仅含播放链接，不含视频文件，远程链接失效后需要重新获取。

导入采用先校验、后合并。空间不足等情况可能留下部分已导入的图片；释放空间后按默认合并重试，可跳过已导入 ID。聊天提交前会在当前空间保留 `before-last-import` 快照。清空本地数据会删除当前空间的聊天、作品、草稿、视频结果和任务记录，保留显示设置及其他账号的数据。

## 刷新后恢复

文字生成中刷新页面，已保存内容保留并标记中断，不自动重发付费请求。

视频按 `GET /v1/videos/{task_id}` 恢复；文生图仅在上游返回 `task_id` 且支持 `GET /v1/images/generations?task_id=...` 时恢复。恢复使用原账号与原密钥，只查询已提交任务，不重新 POST。同步图片生成、图片编辑等未返回任务 ID 的请求无法在页面销毁后自动续接。

原密钥不匹配、查询失败或任务超过一天时保留本地记录，并在账号/设置页提供重新查询和清理入口。清理本地任务不会取消上游任务或退还已经发生的费用。
