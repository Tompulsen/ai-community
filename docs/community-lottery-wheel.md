# 社区抽奖转盘

抽奖入口：`/community/lottery`。管理员入口：`/admin/community-lottery`。

管理员可在同一页面编辑：

- 转盘主题（翡翠青、梦幻紫、暖橘金）、活动标题、副标题、中心按钮文字和补充活动说明；右侧预览实时更新，保存后生效。
- 邀请、作品获赞、粉丝增长的达标门槛、每档奖励次数，以及点赞按单篇或全部作品计算。
- 每个奖品的名称、余额金额（USD）、中奖概率、库存、说明和启用状态；“谢谢参与”使用不发奖类型。

中奖概率直接填写百分比，启用奖品合计必须为 100%，支持 0.01% 精度。保存时转成服务端既有整数权重。只调整外观或其他规则时不重算历史权重。“谢谢参与”也计入总概率；不希望出现的奖项应取消启用。库存为 -1 表示不限；库存为 0 的奖品暂不参与抽取，当前概率按其余奖品重新归一化，因此管理页同时显示设定概率与当前概率。

转盘扇区面积和重复扇区是展示效果，不能代表实际概率。1/3/5 连抽保持一次请求及同一个幂等标识；连抽的转盘展示最后一个奖项，完整结果在下方列出。抽完后的转盘和奖品列表保留本轮快照，刷新后查看最新奖池。超过 12 个奖品时转盘使用编号，下方列表显示对应的完整名称。

开奖、扣次、扣库存和余额入账仍由服务端事务执行。网络结果不确定时查询原请求；前端动画不会重新开奖。管理员并发保存或抽奖造成的版本冲突需重新加载，不能覆盖已消耗的库存。

外观存在现有 JSONB 配置的 `wheel` 字段中，无新增数据库表或迁移。旧配置读取时补默认外观；旧管理客户端省略 `wheel` 时保留已保存的外观。文本按纯文本显示，主题仅允许预设值。

转盘使用用户指定的 lucky-canvas 1.7.26 本地源码，Apache-2.0 许可证及可复现打包说明位于 `packages/frontend/vendor/lucky-canvas/`。集成版本补充了可取消动画、卸载清理、减少动态效果和 Canvas 不可用的回退；不依赖运行时 CDN。Galaxy 作为按钮交互参考，界面继续使用项目现有 Vue、SCSS Modules 和主题变量。
