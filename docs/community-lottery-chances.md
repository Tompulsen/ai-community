# 手动管理用户抽奖次数

管理员进入 `/admin/community-lottery` 的「用户抽奖次数」，选择本站用户后可查看当前剩余次数：

- **追加次数**：在当前剩余次数上增加正整数。
- **设置剩余次数**：直接设为指定的非负整数，填写 `0` 可清零。
- 可填写调整备注；核对确认框中的用户和修改前后次数后，点击「保存次数」。

此操作仅管理员可用，抽奖暂停时也能调整。远程、停用、删除或已迁移的用户不能调整。不会重置已领取任务奖励的进度；余额读取会结算当前符合条件且尚未领取的任务奖励。

管理员日志新增「调整抽奖次数」，记录操作人、目标用户、调整方式、修改前后次数及备注。次数与审计记录在同一数据库事务中保存。

用户抽奖或其他管理员操作导致次数变化时，保存会提示冲突，需要刷新后重新确认。网络异常时使用「核对本次调整」重试原请求，同一请求不会重复增加次数。

## 接口

- `admin/community/lottery/account`：传入 `userId`，返回用户与当前 `balance`。
- `admin/community/lottery/adjust-chances`：传入 `userId`、`mode`（`add` / `set`）、整数 `amount`、读取到的 `expectedBalance`、唯一 `requestId` 和可选 `reason`。

每次新调整生成一个新的请求 ID；请求结果不明时必须保留原 ID 和参数重试。余额范围为 `0–2147483647`，备注最多 300 字符。余额达到上限时暂缓结算新任务奖励，允许继续抽奖或手动调低；后续按当时的任务条件结算。
