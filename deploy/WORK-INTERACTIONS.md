# 社区作品互动与详情（2026-11-05）

社区作品卡片增加快速评论、原生转发、爱心点赞、浏览量和复制作品链接。点击标题或媒体进入 `/community/work/:submissionId`：桌面左侧展示完整作品，右侧显示作品信息、制作同款和评论；窄屏依次上下排列。图片、动图与视频复用既有上传文件，视频手动播放，多附件可切换，敏感文件需主动展开。

“制作同款”使用现有 `/create/image`、`/create/video`、`/create/text` 路由及后台链接配置，继续由制作页面要求登录。提示词单独提供复制按钮，不假设第三方工具支持自动填入。

## 数据与行为

- 点赞、转发和评论使用已有 Note API。点赞合并缓冲中的爱心反应；转发次数是原生操作数。
- 转发收到成功响应后锁定成功态；网络结果不确定时不自动重发。不会调用会删除多条引用的批量取消转发接口。
- 评论成功后才清空草稿；失败保留内容，未确认送达时要求先核对。列表和详情之间共享同账号、同作品的会话内草稿和转发状态；刷新浏览器不保留。
- 评论按原生游标分页，只显示当前查看者可见且公开的评论，不展示已删除、隐藏或带内容警告的回复。
- `community/works/show` 和 `community/works/view` 同用公开状态、作者隐私、拉黑及访客权限检查。
- 浏览量在预览进入可视区域且页面可见满 1 秒后上报；账号或服务端请求 IP 哈希在 Redis 去重 30 分钟。只存哈希，不存原始 IP。数据库原子累加并持久保存；卡片与详情共用去重窗口。
- 新迁移 `CommunityWorkViews1793844969747` 为既有投稿补零，提供 up/down。历史浏览无法回填，统计从本功能上线开始。
