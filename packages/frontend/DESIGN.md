# 创作社区：界面设计约定

2026-11-06。用户确认：浅色极简，深色科技展示区。本约定替代此前首页的奶油色、彩色贴纸、倾斜卡片和厚描边方向。

## 视觉与内容

- 首页采用白色导航、浅灰底、深色正文、蓝色主操作。右侧以中性深色展示管理员图片／动图或真实热门作品。不得添加虚构作品、活跃人数或生成进度。
- 应用界面沿用 Misskey 主题变量，以清晰边界、12px 容器圆角和8px 操作圆角统一社区、个人页、详情、制作入口和账户弹窗。用户自选主题继续生效。
- 默认浅色主题：背景 `#f5f7fa`，面板白色，正文 `#273343`，主操作 `#315ee8`。深色展示区 `#11151c`，次级面 `#1b222d`，文字 `#f4f6fb`，辅助文字 `#acb8c9`。
- Inter 可变字体随应用部署，中文由本地中文无衬线字体接续；禁止为字体请求第三方跟踪服务。标题与正文有明显层级，避免在应用中重复营销大标题。
- 社区保留完整左侧导航、最新作品附近的分区和右侧搜索／管理员公告／创作者。窄屏访客使用横向导航，让作品获得完整宽度。
- 右侧搜索、公告、创作者合并为可收起的发现侧栏。桌面默认展开并在本机记住选择；收起后作品区使用全部剩余宽度，评论预览随之重新计算。窄屏默认关闭，通过顶部“发现社区”打开右侧抽屉，支持关闭按钮、遮罩、Esc 与键盘焦点返回；关闭不丢失搜索输入。

## 交互与可访问性

- 导航状态通过文字、底色和 `aria-current` 同时表达。按钮、输入、选择器保留可见焦点与清晰边界。
- 分享按钮只在剪贴板成功后显示确认图标；失败保留链接与重试路径。异步结果在组件停用或作品切换后失效。
- 2026-11-06 用户追加要求：保留整体展示排版，明显增强动态交互与设计辨识度。首页以“文本、图片、视频汇聚为创作”的叠层展台作为动态焦点；制作入口悬停／聚焦与对应图层联动，保留三项入口、社区与账户流程。
- 展台图层及分类按钮用于切换本类别热门作品，原位提供登录后的点赞、评论；顶部三项制作导航继续进入制作页面。空类别、读取失败与切换中状态有明确反馈，未登录者可浏览并在写入互动时打开登录窗口。
- 动效分为首页展台的一次 750ms 入场、最大 4–5° 的局部指针视差、180–520ms 的状态过渡，以及成功后确认的点赞／转发／分享反馈。主要内容、真实作品与按钮点击区域保持稳定；不增加循环背景动画或滚动劫持。
- 系统减少动态效果或站内关闭动画时，关闭新增动画、视差与图层移动，保留色彩和文字状态。指针只使用精确指针，触摸一次点击即可导航；离屏、窗口隐藏、组件停用和卸载清理待执行帧与状态。
- 视频悬停静音预览、离开／离屏暂停、触屏手动播放等原有行为保持。
- 社区作品卡片在可用宽度充足时采用左侧作品与互动、右侧评论预览。右栏按实际可用高度连续展示能完整容纳的评论预览，不固定条数；长评论最多三行摘要，保留作者及附件入口。窄屏放到作品下方，按视口高度调整预览空间。
- 评论预览不设置内部滚动、不拦截滚轮。窗口、内容、字体或输入框高度变化后重新测量；容纳不下的行同时从视觉、键盘及辅助技术中隐藏。全部评论通过作品详情访问，直接评论仍在卡片内完成。
- 卡片进入可视区域后读取评论；仅在还有展示空间时自动补页，连续空页、失败或离屏时停止补齐。网络分页大小不作为展示条数限制，详情页保留显式加载更多。
- 作品详情继续采用左侧作品、右侧内容与评论的结构，制作同款进入相应制作入口。外部站点嵌入策略由原站决定。
- 认证、邀请注册、审核、编辑删除、附件安全处理和中英界面均保持原有业务规则。

## 资源与来源

- Galaxy：进一步改造已有 `Buttons/0x-Sarthak_hungry-penguin-30.html` 的方向性填充、箭头与按压反馈，改用 transform 而不动画改变宽度；保留 MIT 声明。
- Taste Skill：首页与应用分别处理；以真实作品承担视觉重点。
- Impeccable：依据实际布局检查响应式、状态、对比度、键盘与触屏。
- LeiBox：参考本地 `stacked-metadata` 的同节点叠层展开、快速反向与生命周期边界，以及 `share-invite` 的成功反馈。移植交互方式到本站制作入口与原有 Vue 状态，通过 CSS 过渡完成；未复制受限引擎、弹簧实现、示例商标或第三方素材，不引入 GSAP／WebGL。
- Inter：原始可变字体来自 Inter 项目 `docs/font-files/InterVariable.woff2`；SIL OFL 1.1 及版权文本保留于 `assets/fonts/Inter-OFL.txt`。

## 验收

桌面、390px、320px；中英语言；访客与账户窗口；主题与减少动效；社区作品、详情、评论、分享、个人作品编辑及制作入口。只有实际执行的检查才记录为通过。


## 手机社区图库与作品详情（2026-11-10）

用户追加三张参考图后，公开社区在 700px 及以下使用以下布局，覆盖此前每屏一张的首页方案。桌面、个人作品、审核和创作工具保持原有页面职责。

- 首页采用社区主题背景与等宽双列作品卡片；封面统一为 3:4、居中裁切，标题固定预留两行，作者与点赞行逐排对齐，横图不再单独占整行。展示真实作品封面、标题、作者和点赞数，完整媒体在作品详情查看。卡片只导航，不自动播放视频或为每张卡片预读互动状态。搜索、分类、标签、分页及详情返回后的滚动位置继续复用已有能力。
- 作品点击进入全屏详情，保留比例展示图片或视频，右侧依次为作者/关注、点赞、评论、收藏、转发分享和“做同款”；底部沿用首页、创作、投稿、消息、我。低矮横屏调整操作区域，支持安全区、键盘焦点、敏感附件及多媒体切换。
- 关注/取消关注及关注申请、收藏/取消收藏、作品赞、评论赞、转发均使用现有接口。操作前读取状态，失败时显示可恢复的反馈；游客写入操作引导登录，不使用虚构数量或本地假状态。
- 评论采用社区主题底部面板，占视口约 64%，最高 680px；作品缩至上方剩余区域，视频暂停。头像、作者、正文、时间、回复入口及点赞保持清晰层级，输入区固定在底部；回复入口进入已有评论线程。支持遮罩、Esc、焦点限制及焦点返回。
- 分享面板提供系统支持时的原生分享、复制链接、站内转发和举报。只有剪贴板写入成功才显示已复制；不自动向外部联系人发送内容。
- “做同款”携带作品 ID 进入对应 AI 工作台，沿用原有提示词、模型、参考图确认及来源关联流程。展开详情可查看完整提示词、模型、授权、来源和参考素材。
- 手机界面统一继承当前社区主题：背景、卡片、导航、搜索、发布、评论、分享及展开详情使用既有主题令牌；选中状态与主要操作使用主题强调色，点赞沿用主题点赞色。兼容浅色、深色和用户自定义主题，不再强制黑底或粉青双色。实际媒体区域保留中性深色背景及高对比覆盖文字。
- 手机应用页面（包含设置、创作、消息）统一使用「首页、创作、发布、消息、我」底栏，切换页面不再退回旧图标菜单；设置对应「我」，创作与消息各自显示选中状态。官网首页仍保留独立展示布局。设置左上提供返回：窄屏子页回设置列表，设置列表及宽屏设置回本人主页；直接打开设置也有明确的站内返回目标。
- 视频底部为独立的 88px 控制区，进度与播放按钮触控高度均至少 44px；右侧互动与“做同款”避让控制区，矮屏采用紧凑布局并避让顶部导航。评论/分享打开时隐藏播放器控件。
- 视频复用单播放控制器，离屏、弹层和后台暂停；省流量与减少动态效果时保留手动播放。首页不再使用纵向 scroll snap。
- 以用户截图和本地 Douyin 的 WaterfallList、ItemToolbar、BaseFooter 为结构参考，沿用本项目 Vue 组件、主题令牌和字体图标，未复制参考项目源码、人物、品牌或媒体。Galaxy 复用既有按压反馈；Taste/Impeccable 用于排版、响应式、状态及可访问性检查。
- 手机个人页与作者页参考本地 Douyin 的 `pages/me/Me.vue`、`Me.less`、`components/UserPanel.vue` 与 `slide/SlideUser.vue`：头像与身份并排、圆角资料面板、主题色关注/编辑、吸顶搜索与作品分区、三列封面墙。上滑收起资料后仍可搜索和筛选；点击头像进入作者公开作品，作品详情可返回原个人页位置。
- 复用现有作者作品接口与隐私规则，只显示真实公开作品及可见关注统计，不以动态数或当前页点赞合计假装作品总数/累计获赞。本人提供作品管理、收藏、创作、设置；他人提供关注和已有公开动态入口。未加入商品、直播等无关业务。参考源码以布局与交互研究为主，未导入其业务数据、素材或依赖。


## 手机个人页分区交互（2026-11-10）

以用户提供的主页操作视频，以及本地 Douyin 的 SlideRowList / Indicator / Posters 为结构和动效参考，沿用当前社区主题与 Galaxy 既有按钮反馈，不导入参考源码、媒体或依赖。

- 作品、动态、收藏、喜欢在主页内切换。浏览器原生横向滚动吸附驱动面板和选中下划线，支持触屏滑动、点击、方向键和 Home/End；减少动效时点选直接定位。
- 资料区和底栏维持同一页面，分区栏吸顶，各分区保存独立浏览位置。已访问分区保留数据，作品详情返回后恢复原分区与位置。
- 作品继续使用作者公开作品接口；动态、收藏、喜欢复用已有原始记录分页。收藏仅本人可见，喜欢按心形反应筛选并遵循公开设置。隐藏或远端喜欢提供说明，不发送不适用请求。
- 收藏和喜欢通过有界 noteIds 批量查询关联公开社区作品，继承服务端可见性检查；普通动态进入原笔记详情，内容提示与敏感附件不展示封面。
- 返回主页会核验当前分区，保留已加载分页长度；后台请求不消耗返回刷新标记。失败展示重试，不能把翻页失败当成内容结束。
- 本人收藏快捷入口进入页内收藏；主页搜索切回作品结果。未加入购物、直播等无关业务。
