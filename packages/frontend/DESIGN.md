# 创作社区：界面设计约定

2026-11-06。用户确认：浅色极简，深色科技展示区。本约定替代此前首页的奶油色、彩色贴纸、倾斜卡片和厚描边方向。

## 视觉与内容

- 首页采用白色导航、浅灰底、深色正文、蓝色主操作。右侧以中性深色展示管理员图片／动图或真实热门作品。不得添加虚构作品、活跃人数或生成进度。
- 应用界面沿用 Misskey 主题变量，以清晰边界、12px 容器圆角和8px 操作圆角统一社区、个人页、详情、制作入口和账户弹窗。用户自选主题继续生效。
- 默认浅色主题：背景 `#f5f7fa`，面板白色，正文 `#273343`，主操作 `#315ee8`。深色展示区 `#11151c`，次级面 `#1b222d`，文字 `#f4f6fb`，辅助文字 `#acb8c9`。
- Inter 可变字体随应用部署，中文由本地中文无衬线字体接续；禁止为字体请求第三方跟踪服务。标题与正文有明显层级，避免在应用中重复营销大标题。
- 社区保留完整左侧导航、最新作品附近的分区和右侧搜索／管理员公告／创作者。窄屏访客使用横向导航，让作品获得完整宽度。

## 交互与可访问性

- 导航状态通过文字、底色和 `aria-current` 同时表达。按钮、输入、选择器保留可见焦点与清晰边界。
- 分享按钮只在剪贴板成功后显示确认图标；失败保留链接与重试路径。异步结果在组件停用或作品切换后失效。
- 动效集中于操作反馈和有明确方向的按钮图标；不添加持续背景动画。减少动态效果偏好关闭新增动画。
- 视频悬停静音预览、离开／离屏暂停、触屏手动播放等原有行为保持。
- 作品详情继续采用左侧作品、右侧内容与评论的结构，制作同款进入相应制作入口。外部站点嵌入策略由原站决定。
- 认证、邀请注册、审核、编辑删除、附件安全处理和中英界面均保持原有业务规则。

## 资源与来源

- Galaxy：沿用项目已有的方向性按钮反馈与原有 MIT 声明。
- Taste Skill：首页与应用分别处理；以真实作品承担视觉重点。
- Impeccable：依据实际布局检查响应式、状态、对比度、键盘与触屏。
- LeiBox：参考本地 `stacked-metadata`、`share-invite` 与 `ai-generating` 的交互目录；最终仅采用“操作后确认、紧凑反馈、必要时展开”的思路，复用项目 Vue 状态与 CSS 实现。本次不复制 LeiBox 引擎、示例商标或授权未明确的代码，不引入 GSAP／WebGL。
- Inter：原始可变字体来自 Inter 项目 `docs/font-files/InterVariable.woff2`；SIL OFL 1.1 及版权文本保留于 `assets/fonts/Inter-OFL.txt`。

## 验收

桌面、390px、320px；中英语言；访客与账户窗口；主题与减少动效；社区作品、详情、评论、分享、个人作品编辑及制作入口。只有实际执行的检查才记录为通过。
