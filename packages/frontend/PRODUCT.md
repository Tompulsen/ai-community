# AI 创作社区

## Platform
Web，桌面与移动端浏览器。

## 已确认的产品要求
- 在现有 Misskey 上扩展，保留 Vue、账号、上传、评论与用户管理能力。
- 三个固定社区：视频；图片；文本、代码与开源 Skill。
- 每个作品可分享、评论交流；提供登录与注册入口。
- 左侧固定显示三个社区导航，第三方 AI 调用预留入口。
- 2026-11-04 用户明确选择发布前审核，通过后公开。
- 本聊天负责前端；本轮新增审核 API 为待后端实现的契约，不能把 UI 状态当作权限控制。

## 参考与约束
Galaxy：组件反馈参考；Taste Skill：应用界面视觉规则；Impeccable：沿用 Misskey 的界面体系，补齐响应式、空态与交互状态。
本轮为现有视觉系统的功能扩展，沿用 MI_THEME 主题变量、Tabler 图标与原有字体，不进行品牌重设计。

## 尚未确定
正式品牌名称、AI 服务供应商和计费、生产部署配置、审核后端实现与待审附件私有存储。

## 已确认的 UI 方向（2026-11-04）
用户指定以 Misskey 社区平台为主要 UI 参考。以本仓库 timeline.vue、MkNote.vue 和 Mi Light 主题作为依据：固定侧栏、紧凑页头、居中单列作品信息流、作者在前、媒体在正文后、圆角面板、主题强调色和右侧辅助面板。继续使用三项必用设计资源，但不改变 Misskey 的社区视觉语言。

## 简洁化方向（2026-11-04）
用户要求界面更加大气简洁：保留 Misskey 视觉体系，合并重复页头，以更宽的单列作品区和清晰字号层级突出内容；右侧说明收为底部可展开指引，精简分隔与无封面占位。登录、投稿、搜索、审核及评论入口保持可用。

## X 参考与三资源精修（2026-11-04）
用户补充 X 首页截图作为结构参考，并再次明确要求调用 Galaxy、Taste Skill、Impeccable 优化 UI。以连续作品信息流、左侧文字导航、顶部社区标签、就地投稿入口为主；不用截图中的账号状态、人物或作品作为本项目内容。正式 UI 继续遵循 Misskey 用户主题，保留三社区、评论与发布前审核流程。

## 全宽柔和布局（2026-11-04）
