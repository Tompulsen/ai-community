# AI 创作社区

## Platform
Web，桌面与移动端浏览器。

## 已确认的产品要求
- 在现有 Misskey 上扩展，保留 Vue、账号、上传、评论与用户管理能力。
- 三个固定社区：视频；图片；文本、代码与开源 Skill。
- 每个作品可分享、评论交流；提供登录与注册入口。
- 左侧固定显示三个社区导航，第三方 AI 调用预留入口。
- 2026-11-04 用户明确选择发布前审核，通过后公开。
- 本轮补齐社区投稿、作者历史、公开列表与管理员审核 API；权限与审核状态由后端验证。

## 参考与约束
Galaxy：组件反馈参考；Taste Skill：应用界面视觉规则；Impeccable：沿用 Misskey 的界面体系，补齐响应式、空态与交互状态。
本轮为现有视觉系统的功能扩展，沿用 MI_THEME 主题变量、Tabler 图标与原有字体，不进行品牌重设计。

## 尚未确定

保留用户要求的全宽工作区和已取消的重复展示栏。本轮先本地验证与截图，不推送、不部署。

## 官网首页（2026-11-05，本地待预览）
首页 `/` 使用用户给定的 playful 参考图：奶油底色、深色描边、紫色右侧主视觉、两栏布局，铺满窗口。标题与文案基于本项目真实创作和社区功能，使用当前站点名称及 Logo，不加入虚构数据。此风格仅用于官网及后台中的首页图片预览，社区与管理员操作界面继续沿用现有主题。

顶部依次为文本制作、图片制作、视频制作。游客点击或直接访问 `/create/:kind` 时必须先登录本站账号；登录成功保留当前制作路径。取消登录时保留登录提示及返回首页、浏览社区入口，不加载外部制作页面。第三方制作服务自身的账号与访问规则由对应服务管理。

左下“进入创作社区”指向公开 `/community`，无需登录。右侧使用项目 Logo 的默认排版，可在“管理后台 → 官网首页”上传或选择 PNG/JPG/GIF/WebP/APNG 图片，也可设置 HTTPS 图片地址。复用现有 `mascotImageUrl` 数据库配置及原生上传，保留原图动画，最大 20 MB 且服从服务器及账号限制；保存、恢复默认、失败重试均有明确状态。已关闭动画展示的用户使用原生静态代理。

角色语气统一为好奇、友好、轻松的小章鱼，以“灵感冒泡 / 作品登场”连接色彩、字号与图形。首页增加“中文 / English”选择，持久保存到原生语言偏好并重新加载语言包。首页、制作页面及链接设置、首页图片设置支持中英展示；原生登录注册使用对应语言。管理员设置的站点名称、图片以及用户内容不自动翻译。

## 首页热门作品（2026-11-05，本地待发布）
管理员可在“官网首页 → 展示内容”选择自定义图片 / 动图，或社区热门作品。热门按已审核作品对应公开 Note 的反应、评论、转发总数排序，同分时选较新的作品；始终使用游客可见性规则。展示作品封面、标题、作者与评论数，点击进入对应作品详情。视频使用封面且不自动播放；文档、Skill 或无安全封面的作品使用文字摘要。

模式保存在已有 clientOptions JSON 配置中，无新增数据库列。热门为空或读取失败时使用已保存的图片或默认视觉，保留自定义图片草稿；返回首页会刷新热门结果。新增界面文案支持中文和英文。本轮继续仅本地修改、验证与截图，不推送、不部署。

## 三模块作品窗口与发布授权（2026-11-05）

首页热门模式分为主作品预览、内容/提示词与做同款、作品信息/点赞/在线评论三个模块，手机依次排列。点赞与评论复用真实 Note API，游客操作先登录；做同款复制内容后进入对应制作页。视频支持手动播放。评论草稿与发送不确定状态按账号、作品保留到当前浏览器会话内的站内路由往返，防止误重发；浏览器刷新不保留。

用户随后明确要求“优化好部署”，覆盖此前仅本地预览的限制；本轮通过检查后发布 Docker 镜像并更新服务器。实际部署版本与验证记录见 deploy/STATUS.md。
