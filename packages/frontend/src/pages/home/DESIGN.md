# 官网首页设计

2026-11-06：本次全面改版采用用户确认的“浅色极简 + 深色科技展示区”。以 ../../../DESIGN.md 为当前设计规范，替代此前的 playful 贴纸风格。

首页保留三项制作入口的登录校验、公开社区入口、中英切换、管理员图片／动图及热门作品展示。热门作品仍由作品展示、内容／提示词与制作同款、作品信息与评论三个部分组成。背景、边界、字体和动作反馈使用统一色板，作品原始内容不被裁切或重着色。

## 动态交互精修（2026-11-06）

用户要求保留整体排版、加强动态交互。保留桌面两栏比例、导航、文案与展示区外框，默认品牌视觉改为文本／图片／视频围绕站点 Logo 的创作展台。顶部制作入口的鼠标与键盘焦点联动对应图层，点击仍进入本站账户校验后的制作页面。三个展台图层及底部分类按钮点击后，在原展示区展示该类别最热的公开作品；文本映射为社区 resource 类别。图层没有伪造作品、计数或生成进度。

展台入场只播放一次，不持续循环；鼠标移动只影响装饰层，图片／动图及热门作品原内容保持稳定。系统或站内关闭动画时保留静态构图与操作状态。手机保持全宽堆叠，三个展台入口各保留至少44px点击高度。首页独立 accountDialogLoaders 不得合并，确保生产登录窗口样式预加载。

热门作品模式保留分类按钮及返回展示入口，复用 WorkPanel 的作品、提示词、做同款、点赞和评论。游客可浏览，写入互动需登录本站账户。切换时取消旧请求并按作品身份重建互动面板，草稿按账户与作品保存。服务端先筛选类别再按点赞／评论／转发总和排序，遵循匿名可见范围与审核状态；同热度按较新投稿优先。分类无作品或请求失败时明确展示空状态／重试，不用其他类别替代。管理员的默认展示配置仍决定初始展示及返回后的内容。

公开首页在当前浏览器标签页保存选中类别，通过白名单恢复，以便登录导致整页刷新后继续浏览该类作品；返回展示时清除。存储不可用不影响本次切换。管理员预览不读写此状态。
