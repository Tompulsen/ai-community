# 官网首页

Surface: `/`. Mode: Persuade。用户提供截图为视觉依据；参考网站没有返回可读取内容。

首屏回答“从哪里开始创作，在哪里发现大家的作品”。顶部仅三个制作入口，账户操作单独位于右侧；左侧下方突出无需登录的社区入口。首页移除社区侧栏，进入社区后恢复原有导航。

配色在 palette.scss 集中声明：奶油纸底、墨色文字与描边、紫色展示板、珊瑚账户按钮、少量黄色与嫩绿点缀。使用项目原有字体与管理员 Logo；不冒充参考站品牌。硬阴影和粗描边来自用户指定的 playful 参考。右侧图完整 contain 展示，未设置或加载失败时显示默认项目 Logo 排版。

桌面两栏比例约 44:56，宽屏无固定内容宽度上限；800px 以下纵向排列，手机仍直接展示三项制作导航。所有操作有可见键盘焦点，减少动态偏好下取消位移动效。

Galaxy 的按钮反馈作为 hover/press 思路参考，未复制第三方源码；Taste Skill 用于版式与后台信息层级；Impeccable 用于交互状态、响应式及实机视觉验证。管理员配置只扩展既有主题，不套用首页营销风格。

## 角色语气细化
用户补充强调一致性与克制：性格为好奇、友好、轻松的小章鱼。用“灵感冒泡 / 作品登场”连接文案和真实 Logo，采用统一的中文无衬线字体栈。夸张仅放在主标题、章鱼排版与少量贴纸，移除展示板上重复的三个类别标签及导航锁图标。导航、表单与错误提示保持直接清楚。按钮 hover/press 150ms，保存成功后 180ms 反馈；没有人为等待，没有循环漂浮动画。减少动态偏好下停用装饰反馈并使用静态图片代理。

## 社区热门模式
用户要求右侧纸卡也可展示社区最火作品。沿用紫色展示板、倾斜纸卡和一个嫩绿贴纸，将纸卡内部替换为作品类型、封面或摘要、标题、作者及评论数。整张纸卡链接至已审核作品详情；贴纸不遮挡标题，未增加自动轮播或视频自动播放。封面遵守敏感标记与减少动态偏好，加载失败时显示作品摘要。

后台通过带文字的两个原生单选项切换模式，并就地展示热度规则、即时预览、加载 / 空态 / 错误和重试。热门模式的回退预览以已保存图片为准。截图中的作品与互动数是明确标注的本地示例，不作为线上数据。

## 三模块作品窗口（2026-11-05）

热门作品改为左上黄色主预览、右上珊瑚色内容/提示词与做同款、底部奶油色作品信息与互动区。宽屏上下两层，窄容器按预览、提示词、评论依次堆叠。图片完整展示；视频提供原生播放控制，不自动播放。

复用公开 Note 与回复接口；游客可浏览，点赞和评论打开原生登录。爱心点赞单独计数，已有其他表情时明确替换。内容复制成功后进入对应制作页，需要自行粘贴，不承诺第三方工具自动填充。评论发送中禁重复提交，未知结果保留草稿与重发锁，账户和作品隔离的内存草稿支持站内路由往返；刷新浏览器仍会清空。敏感附件始终使用最新匿名 Note 标记。中英文、手机、失败和空态均有对应文案。
